A one-line excuse a robot vacuum gives for missing a spot, for the
[make.fun bounty](https://make.fun/bounty/u-golden-heron-44-the-robot-vacuum-s-best-excuse-53412214).

## Run

```sh
node main.ts
```

It writes one line (95 characters) to `/output/entry.txt`:

> My cliff sensors identified that dust bunny as a staircase, so I have elected not to die today.
